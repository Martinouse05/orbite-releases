# Orbite – appli Android

Ce dépôt contient seulement le fichier d'installation de l'appli **Orbite** (les maths du lycée en mode jeu). Le code source est privé.

**Installer ou mettre à jour :** sur votre téléphone Android, touchez le fichier `Orbite.apk` ci-dessus, puis « Download » (ou « Télécharger »). Ouvrez le fichier téléchargé et touchez « Installer » ou « Mettre à jour ». Vos données restent sur votre téléphone.

Une fois installée, l'appli vous prévient d'elle-même quand une nouvelle version est disponible.
